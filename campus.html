CAMPUS TOUR & SAFETY ENVIRONMENT

校園環境與安全實境開箱

座落於高雄市楠梓區軍校路 880 巷靜謐巷內，右昌國小正對面。
避開大馬路車流與嘈雜喧囂，兼具明亮採光、溫暖木質調環境與無死角的安全防護，為孩子打造兼具專注與放鬆的學習綠洲。

SPACE SHOWCASE

走進真實空間・看見用心設計的每個細節

打破傳統補習班壓迫擁擠的格子間，為孩子營造安心自在的第二個家。

FLOOR 01 · RECEPTION

一樓溫馨接待大廳與親師溝通區

溫暖木質調接待大廳，是孩子放學進班的第一道微笑，也是家長最信賴的交流平台。透明開放的櫃檯設計，方便家長接送時隨時與專任導師面對面交流當日學習與情緒狀態。

  • ✓ 每日接送簽到與出入安全管理
  • ✓ 獨立洗手台與體溫量測動線
  • ✓ 溫暖木質書報接待休憩座椅
FLOOR 02 · MAIN CLASSROOM

二樓大教室：專注課輔與自律作業區

大面採光通風窗，搭配護眼無眩光 LED 柔光燈具。寬敞方正的空間格局，每位孩子享有足夠寬裕的獨立課桌椅與個人收納抽屜。專任老師桌邊隨時陪伴，確保作業專注度與即時訂正。

  • ✓ 寬大桌面設計，擺放作業評量不擁擠
  • ✓ 良好通風對流與全天候溫度監控
  • ✓ 專任導師桌邊一對一坐姿握筆雕琢
FLOOR 02 · INQUIRY STUDIO

二樓小教室：分組探究與生活美語教室

專為小班分組互動、生活美語情境口說與珠心算靜心訓練量身打造。配備教學大黑板，老師在此引導孩子進行心智圖段落梳理、專案發想與同儕討論，營造生動有趣的探究氛圍。

  • ✓ 超高專注度的獨立小班空間
  • ✓ 心智圖與專案發表大黑板牆
  • ✓ 珠心算專注靜心與口說情境專區
INTERACTIVE LEARNING

同儕激盪與心智圖引導實景

打破「一個人在座位上悶頭寫」的孤立感。在適當的探究環節，孩子們圍坐討論、共同繪製思維架構圖，由老師在旁提問引導。動態探究與靜態深思交替進行，激發孩子強烈的求知慾。

  • ✓ 1:15 小組合作思維激盪
  • ✓ 老師引導提問，培養論點結構
  • ✓ 多元主題探究，提升自主表達力
SAFETY PROTOCOL

全方位校園安全防護與接送網絡

從放學鐘響到離班回家，每一步都有專任師資貼心護航。

🏫 右昌國小正對面・靜巷安全第一

教室坐落於軍校路 880 巷內，與右昌國小校門僅隔一條靜謐巷道。完全避開主幹道呼嘯而過的車流與汽機車廢氣，孩子放學轉個彎就能進班，步行環境極為安全純淨。

🚶 專任導師步行導護整隊帶回

針對右昌國小、莒光國小的學生，放學時段一律由尚學專任老師親自前往學校指定接送區整隊清點人數，穿著導護背心引導過馬路，一路步行安全帶回教室。

🚐 周邊學校車輛定點安全接送

針對加昌國小、屏山國小、援中國小、油廠國小的學生，由尚學安排專人接送服務，放學在校門口指定位置核對學生姓名，確保每位孩子準時、安全抵達班內。

🧼 嚴格日常環境衛生與健康把關

進班落實雙手消毒清潔與健康觀察；每天下課後全班課桌椅以醫療級酒精徹底擦拭，教室定期進行紫外線臭氧空氣清毒，杜絕季節性流感與腸病毒交叉傳染，守護每個孩子的健康。
